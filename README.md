### 5. Company Growth Insight Model
**Folder:** [company_growth_insight_model](company_growth_insight_model)  
Predicts and analyzes company growth potential using AI. Tracks 13 critical features and explains predictions with SHAP analysis.

**Key Features:**
- Predict company growth potential from 0% to 100%
- Track employee growth, job postings, and other key metrics
- Real-time metrics for 24,000+ companies
- SHAP analysis for explainable AI insights
- Interactive Streamlit dashboard for exploration
- Powered by XGBoost machine learning

- Predicts power distribution with ML models
- Uses LSTM and XGBoost for high accuracy
- Data preprocessing and feature engineering included
- Supports analysis for energy optimization and decision-making
